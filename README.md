# Jarvis: AI Voice Assistant

A Python voice assistant inspired by Iron Man's J.A.R.V.I.S. It listens to your voice commands, understands them, and replies by speaking back.

## Features

- Voice input: listens through your microphone and converts speech to text
- Voice output: speaks responses aloud with text-to-speech

1. Run the script and wait for Jarvis to greet you.

3. Jarvis responds by voice.
